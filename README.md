# StoryForge Android

## StoryForge 1.3.9

- Ein ausgewählter Videoclip wird über **Clip abspielen** nur zwischen seinem gespeicherten Anfang und Ende wiedergegeben. **Ganzen Film abspielen** bleibt separat verfügbar.
- Clips lassen sich nach **0,5 Sekunden gedrückt halten** mit Haptik verschieben, ohne horizontales Scrollen aufzugeben.
- Beim Videoschnitt zeigt ein Bildstreifen neun Vorschauframes über die vollständige Videodauer; mit zwei Griffen lassen sich In- und Out-Punkt ziehen. Der markierte Bereich kann vor dem Speichern separat abgespielt werden.
- Schnittpositionen werden zerstörungsfrei im Projekt gespeichert, die Originalmedien bleiben unverändert.

GitHub Actions führt die Android-Unit-Tests aus und stellt eine APK im [Releases-Bereich](https://github.com/dmpcwien/StoryForge-Android/releases) bereit.
